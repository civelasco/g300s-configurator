Can't reach your mouse

Make sure it's plugged in. Otherwise, macOS needs to let this app see the mouse:
open System Settings → Privacy & Security → Input Monitoring, turn on G300s Configurator,
then quit and reopen the app.

In Settings, switch G300s Configurator on. If it's already on, select it, remove it with −, add it back with + (from Applications), then reopen the app.
